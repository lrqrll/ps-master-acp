# PS MASTER

Photoshop ACP 互動學習平台，支援電腦、平板與手機。

[開啟 PS MASTER](https://lrqrll.github.io/ps-master-acp/)

## 內容

- 觀念教室：22 個主題、互動圖解、情境解析、名詞搜尋與待複習。
- 入門操作：10 課、20 個引導步驟，獨立保存畫布與進度。
- 439 道文件題目、補充觀念與看圖辨識。
- 31 個可操作的實作任務，包含圖層、遮色片、裁切、文字、調色與圖片匯出。
- 新手、章節、正式模擬考、限時、錯題、看圖、實作與智慧混合模式。
- 隨機題目與選項、錯誤解析、成績、倒數與測驗恢復。
- 收藏、筆記、複習規則、學習分析與 JSON／CSV 備份。

## 使用

在 GitHub Pages 網址開啟即可使用。也可用 Chrome 或 Edge 直接開啟 `index.html`。

首頁選「先學觀念」或「從零開始學」。操作課切到「跟著做」，每步按「檢查」；完成觀念與操作後標記課程完成。

教學確認不計入模擬考成績。圖解是簡化示意；直方圖由示例圖實際像素計算，色彩比較不等於完整 ICC 管理。

學習紀錄保存在目前裝置的瀏覽器；不同裝置不會自動同步。可在「分析」匯出 JSON 備份，再在另一台裝置匯入。

這是簡化的 Photoshop 操作模擬器，並非 Adobe 官方產品或官方原題。去背使用內建素材的預備主體範圍；沒有串接 Adobe AI。CMYK 與 PSD 存檔以設定流程模擬，並非完整色彩管理或原生 PSD 編輯器。PNG 與 JPG 可以實際匯出。

正式模擬考預設 50 題、50 分鐘，為平台自訂；正式考模式只使用已整理四個選項的題目，其餘文件轉入題可在學習中心及章節練習使用。

## GitHub Pages 設定

Repository Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save。

入口為 `index.html`，圖片與執行所需檔案均已內嵌，不需要安裝套件或另外建置。

參考：[Adobe Photoshop 考試目標](https://certifiedprofessional.adobe.com/photoshop)。

使用 Fabric.js 與 Lucide；套件原有的授權標示保留在頁面來源中。
