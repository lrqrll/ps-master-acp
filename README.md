# Photoshop 學習室

[開啟網站](https://lrqrll.github.io/ps-master-acp/)

支援電腦、平板與手機；也可直接開啟 `index.html`，不需安裝 Photoshop。

## 觀念課程

17 章、118 個短重點，逐一對應 ACP.docx 的 404 道觀念題，重複概念合併教學。每個重點包含白話說明、例子、詳細解釋、容易混淆處與來源題號。

預設只顯示重點、例子和相關圖解；目錄與詳細內容按需展開。按「下一個」繼續閱讀，不需標記已讀，也不統計學習數量。觀念頁沒有「做一題」或選擇題。目錄可依名稱、英文或題號（例如 Q330）搜尋，也可篩選章節與待複習。

題庫與答題解析中的「看觀念」可直達對應教學。原有測驗成績、筆記、收藏與備份保留。

## 操作與測驗

- 操作教室：10 課、20 個引導步驟，獨立保存畫布。
- 題庫：439 道文件題目（404 觀念、35 步驟），另有補充與看圖題。
- 模擬實作：31 個可操作任務。
- 測驗：隨機題目與選項、答錯解析、成績、限時與進度恢復。
- 其他模式在「練習 → 更多練習」；設定圖示可自訂範圍與題數。

正式模擬考預設 50 題、50 分鐘，為平台自訂。正式模式只抽已整理四個選項的觀念題；其他文件題可在題庫及章節練習使用。

## 保存與限制

測驗成績保存在目前瀏覽器，不會跨裝置自動同步。「成績 → 備份與資料管理」可匯出或還原備份，分析另行展開。閱讀位置與操作畫布可恢復，但不記錄已讀或課程完成數量；舊備份仍可匯入。

這是教學模擬器，並非 Adobe 官方產品或官方原題。去背使用預備主體範圍，沒有串接 Adobe AI。CMYK 與 PSD 以流程模擬，不是完整 ICC 或原生 PSD 編輯器；PNG、JPG 可實際匯出。圖解是簡化示意，直方圖由示例像素計算。

## 維護

入口為 `index.html`，素材及程式均已內嵌。`.nojekyll` 保留於根目錄，GitHub Pages 從 `main` 的根目錄發布。

課程來源對照在開發工作區的 `work/qa/curriculum-coverage.json`，逐一檢查 404 題無缺漏、無重複歸屬。

參考：[Adobe Photoshop 考試目標](https://certifiedprofessional.adobe.com/photoshop)。各課另附 Adobe 或相關官方資料。Fabric.js、Lucide 的原始授權標示保留在頁面來源。
